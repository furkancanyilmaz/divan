# Portreler

Android APK içine gömülen portre görselleri telif nedeniyle depoya
işlenmez. Derlemeden önce `core/tools/fetch_commons_portraits.py` ile
uygun lisanslı (kamu malı/CC) görselleri indirip bu klasöre kopyalayın.
Yaşayan kişilerin gerçek fotoğrafları kullanılmaz; kurgusal karakterler
yerel temsili büstü kullanır.
